# agent-playground

Exploration for the [project_a](https://github.com/crocpool-labs/project_a) agent study: building agents from scratch to see what each piece of scaffolding actually does. Lab notes, not deliverables.

| Folder | What it is |
| --- | --- |
| [`tiny-agent/`](tiny-agent/) | A minimal tool-use loop with no agent framework, run on small local models (Apple Silicon, MLX). Includes a notebook with one successful and two failed runs, a one-variable experiment on tool-description wording, a comparison with LangGraph, and a hand-written inference engine checked against three models. Notes are written in Chinese. |
